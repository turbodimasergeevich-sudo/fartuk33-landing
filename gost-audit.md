# Аудит соответствия сайта требованиям ГОСТ / доступности

**Объект:** https://turbodimasergeevich-sudo.github.io/fartuk33-landing/  
**Дата:** 21.11.2026  
**Нормативная база:** ГОСТ Р 52872-2012 «Интернет-ресурсы. Требования доступности для инвалидов по зрению», ГОСТ Р ИСО/МЭК 40500-2015 (WCAG 2.0, уровень AA). 152-ФЗ упомянут смежно — это закон, а не ГОСТ.

> Автоматический аудит не заменяет экспертную проверку с скринридером (NVDA/JAWS) и ручную проверку скринридером+браузером. Ниже — результат Automated + DOM-аудита и ручных эмуляций.

## Методика

- Lighthouse: Accessibility **100**, Best Practices **100**, SEO **100**.
- DOM-аудит: `alt`, `title` у iframe, имена кнопок/ссылок, labels форм, дубли id, ARIA, заголовки, таблицы.
- Эмуляция ширин: 360 / 390 / 768 / 1280 px — горизонтального скролла нет.
- Проверка `prefers-reduced-motion`, видимого фокуса, skip-link, навигации с клавиатуры.

## Исправлено в ходе аудита

1. Добавлен `scope="col"` в `<th>` таблицы сравнения и админки.
2. Устранён горизонтальный overflow на 360/390 px: все сетки переведены на `minmax(0,1fr)`.
3. Добавлена панель доступности (контраст / без картинок / сброс) с `aria-pressed` и `aria-expanded`.
4. Проверены и подтверждены: skip-link, видимый фокус, `alt`/`title`, `prefers-reduced-motion`, иерархия заголовков.
