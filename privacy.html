Политика обработки персональных данных

Действует с 21.11.2026 · Казань, Российская Федерация

Настоящая политика определяет порядок обработки персональных данных при использовании сайта поставщика 3D-фартуков толщиной 33 мм.

1. Какие данные обрабатываются

  • Имя компании, тип клиента, город;
  • Номер телефона или Telegram;
  • Параметры расчёта (размеры фартука, коллекция, объём);
  • Комментарии к заявке.

2. Цели обработки

Обработка осуществляется для подготовки коммерческого предложения, согласования образцов и партии, а также для обратной связи по проекту.

3. Правовое основание

Обработка производится на основании согласия пользователя, предоставляемого при отправке формы на сайте, в соответствии с Федеральным законом № 152-ФЗ «О персональных данных».

4. Хранение и передача

В демонстрационной версии сайта данные сохраняются в браузере пользователя (localStorage) и не передаются на сервер. При подключении CRM данные будут передаваться уполномоченному оператору по защищённому каналу. Размещение инфраструктуры планируется на территории РФ.

После подключения счётчика Яндекс.Метрики сайт может обрабатывать обезличенные технические данные о посещениях (IP-адрес, User-Agent, URL-ы страниц, переходы по ссылкам) для анализа посещаемости и улучшения сайта. Подключение счётчика производится только после указания идентификатора счётчика в конфигурации сайта.

5. Права пользователя

Пользователь вправе отозвать согласие и потребовать удаления своих данных, обратившись по контактным данным, указанным на главной странице сайта.

6. Изменения политики

Политика может обновляться. Актуальная редакция всегда доступна по этому адресу.
